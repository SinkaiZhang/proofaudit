# ProofAudit v0.1.0

## Purpose

This candidate establishes the first public software contract for fail-closed mathematical proof auditing. It is an alpha research release, not a mathematical certification service.

## Included

- Four-state claim decisions and typed evidence-slot closure.
- Separate assurance dimensions for source, formal, semantic, falsification, and human independence.
- Portable case schemas and plugin manifests.
- Lean replay and independent Comparator integration interfaces.
- Human-review evidence binding and signature-verification support through case plugins.
- Isolated `proofaudit test-e2e` execution with non-adjudicative output.
- GitHub Actions smoke CI and clean-wheel release preflight.

## Validation performed

On 2026-09-18, the candidate wheel was built and installed in a fresh virtual environment. Packaged schemas, the console script, unit tests, case validation, and the minimal ten-stage E2E passed. The companion Ehrhart development case also completed all fifteen stages under disposable synthetic reviews; that result is `TEST_ONLY` and is not expert adjudication.

## Known limitations

- The public benchmark is a development release; the sealed evaluation is not published.
- Plugin execution is trusted code execution.
- Formal kernel acceptance does not by itself establish semantic equivalence to a paper statement.
- Human review remains necessary for real semantic closure.
- Large external tools and sources require independent installation and license review.
